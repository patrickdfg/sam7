# 삼국지: 칠성용옥전 v4.0 Ultimate Edition (2.5D HD 도트 RPG)

## 🌟 v4.0 Ultimate 최종 완성 기능
1. **5막 장편 캠페인 & 제갈량 군사 합류**
   - 제1막 탁군 마을 → 제2막 도원 숲 & 산채 → **제3막 적벽 강변 나루터** → **제4막 호로관 관문** → 제5막 낙양 황궁 제단
   - 유비·관우·장비에 더해 **제갈량**이 4인 스네이크 포메이션으로 합류하며, 전투 시 매 턴 MP 회복 패시브와 **[촉한사걸 천하삼분지계]** 4인 합공 컷인을 발동합니다.
2. **레트로 픽셀 폰트 & 16비트 전용 전투 스테이지**
   - `둥근모꼴(DungGeunMo)` 한글 픽셀 웹폰트 전면 적용.
   - 지역별 16비트 전투 배경 위에서 아군/적군 전신 도트 스프라이트가 직접 돌진·피격·슬래시·플로팅 데미지 연출을 펼칩니다.
3. **서브 퀘스트 3종 & 3칸 멀티 세이브 슬롯**
   - 마을 약초 의뢰, 잃어버린 황금 나침반(보상: `학창의 비단갑`), 호로관 군량미 보급 상자 회수.
   - 3개 세이브 슬롯에 개별 저장/불러오기/삭제 가능.
4. **충돌 박스 디버그 모드 (`F2`) & 하이브리드 오디오 & PWA 앱화**
   - `F2` 키(또는 설정 메뉴)로 충돌 영역과 마우스 좌표를 실시간 확인하며 맵 튜닝 가능.
   - `assets/bgm_village.mp3`, `assets/bgm_boss.mp3` 등 고음질 MP3 파일을 넣으면 자동 재생, 없으면 내장 16비트 칩튠 엔진으로 자동 폴백.
   - `manifest.json` + `sw.js` 탑재로 스마트폰 홈 화면에 앱으로 설치(PWA) 및 오프라인 플레이 지원 + SNS 공유 OG 태그 완비.
